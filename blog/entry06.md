# Entry 6: Presenting My Freedom Project
##### 5/20/26

## Context


The tool I have selected was [phaser](https://phaser.io), and I chose to make a hard platformer game with many randomization aspects to it such as where some items spawn or enemies spawn. I decided to name it [Starbound Steps](https://ramsesm2071.github.io/sep11-freedom-project/) as it took place in space and you collected stars.

-----
## Engineering Design Process

I am currently in the eigth stage of the Engineering Design Process (EDP), where I communicate the results, and add anything else extra if I would like, which is the beyond mvp. I already have my mvp done and most if not all of my beyond mvp done, I might attempt to add something extra but it could cause bugs, so this is most likely the final result.

-----

## Skills

Some skills I learned were time management and debugging.

I learned to manage my time in order to finish my mvp and not get too ambitious, working on the little things that make my game work before working on anything such as a different background, different sprites, or adding more before everything was fixed and worked properly.

As for debugging, while making the game I had many errors and bugs whether it be an extra parenthesis or putting something that called on a specific variable before that variable was even created, all this taught me how to code better and see errors easier. It also helped me understand the console better as when an error happened it would show up in the console and tell me exactly where the error was in the code on the console as well as what was going wrong.

-----

## Summary

After finishing creating my freedom project I think it taught me a lot more that I didn't know about code as well as helped me be more confident in my coding skill, with things such as some of my takeways like understanding the console and being able to debug my code, fixing it so my project worked again.

-----

## Next Steps

For my next steps I wanted to continue adding onto my freedom project, or maybe make a different game, like a different platformer since I'm already comfortable making a platformer, which would be good phaser practice and I would continue coding on that new game or my freedom project to practice until I'm comfortable attempting a new different type of game.
